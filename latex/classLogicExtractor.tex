{\footnotesize\ttfamily std\+::string Logic\+Extractor\+::derive\+Logic\+Recursive (\begin{DoxyParamCaption}\item[{const std\+::string \&}]{signal\+Name }\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [private]}}



Recursively derives the logic expression for a given signal. 

This function traces back the signal to its driving gates and primary inputs, constructing a logic expression that represents the signal\textquotesingle{}s behavior. It uses memoization to cache previously computed expressions, avoiding redundant calculations.


\begin{DoxyParams}{Parameters}
{\em signal\+Name} & The name of the signal for which to derive the logic expression. \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
A string representing the logic expression for the signal. 
\end{DoxyReturn}

\begin{DoxyExceptions}{Exceptions}
{\em std\+::runtime\+\_\+error} & if the signal is not a primary input, a known wire, or driven by a recognized gate/assignment. Also thrown if an empty input signal name is encountered or if an internal wire has no identified driver.\\
\hline
\end{DoxyExceptions}
The function operates in the following steps\+:
\begin{DoxyEnumerate}
\item {\bfseries{Check Cache (Memoization)\+:}} If the logic expression for the signal is already cached in {\ttfamily logic\+Cache\+\_\+}, it is immediately returned.
\item {\bfseries{Base Case\+: Is it a primary input?}} If the signal is a primary input (present in {\ttfamily primary\+Inputs\+\_\+}), its logic expression is simply its own name.
\item {\bfseries{Recursive Step\+: Is it driven by a gate?}} If the signal is driven by a gate (present in {\ttfamily gate\+Output\+Drivers\+\_\+}), the function recursively derives the logic expressions for all input signals of the gate. These input expressions are then used to format the overall expression for the current signal based on the gate type.
\item {\bfseries{Handle Assign statements\+:}} (Currently not implemented but reserved for future use).
\item {\bfseries{Error Case\+:}} If the signal is not found in any of the above categories, it indicates an error. An exception is thrown, indicating that the signal is either an undriven internal wire or an unknown signal. 
\end{DoxyEnumerate}

Formats a logic expression based on the gate type and input expressions. 

This function takes a \mbox{\hyperlink{structGateInfo}{Gate\+Info}} structure describing the gate and a vector of input expressions (strings) and constructs a logic expression string representing the gate\textquotesingle{}s operation. It handles AND, NAND, OR, NOR, XOR, XNOR, NOT, and BUF gates. It uses \textquotesingle{}$\ast$\textquotesingle{}, \textquotesingle{}+\textquotesingle{}, \textquotesingle{}$^\wedge$\textquotesingle{}, and \textquotesingle{}!\textquotesingle{} operators for AND, OR, XOR, and NOT respectively. If the gate type is unsupported, or if the number of inputs is incorrect for NOT/\+BUF gates, or if a gate requiring inputs receives none, an error string is returned, and a warning is logged.

Handles a non-\/\+ANSI port list in a module. 

This method iterates through the ports in a non-\/\+ANSI port list, extracts the port name, determines its direction (input, output, or inout), and adds it to the appropriate sets (primary\+Inputs\+\_\+, primary\+Outputs\+\_\+, internal\+Wires\+\_\+). It also handles different types of port declarations, including implicit, explicit, and empty ports.


\begin{DoxyParams}{Parameters}
{\em port\+List} & A reference to the Non\+Ansi\+Port\+List\+Syntax object representing the port list.\\
\hline
\end{DoxyParams}

\begin{DoxyItemize}
\item Skips processing if not in the target module (in\+Target\+Module\+\_\+ is false).
\item Extracts port names from Implicit\+Non\+Ansi\+Port\+Syntax and Explicit\+Non\+Ansi\+Port\+Syntax.
\item Handles Port\+Concatenation\+Syntax by logging a warning and skipping the port.
\item Skips Empty\+Non\+Ansi\+Port\+Syntax (placeholders).
\item Uses the port\+Directions\+\_\+ map to determine the direction of each port.
\item Adds ports to primary\+Inputs\+\_\+ and internal\+Wires\+\_\+ if the direction is \char`\"{}input\char`\"{}.
\item Adds ports to primary\+Outputs\+\_\+ and internal\+Wires\+\_\+ if the direction is \char`\"{}output\char`\"{}.
\item Adds ports to both primary\+Inputs\+\_\+ and primary\+Outputs\+\_\+ if the direction is \char`\"{}inout\char`\"{}.
\item Logs warnings for ports with unknown or missing directions.
\item Logs warnings if the port name cannot be determined.
\end{DoxyItemize}

{\em port\+Decl} & A reference to the Port\+Declaration\+Syntax node being processed.\\
\hline
\end{DoxyParams}

\begin{DoxyItemize}
\item It first checks if the current processing context is within the target module. If not, the method returns early.
\item It determines the port\textquotesingle{}s direction by inspecting the port header (Variable\+Port\+Header\+Syntax or Net\+Port\+Header\+Syntax). The direction is extracted using {\ttfamily value\+Text()} to handle keywords represented as text tokens.
\item It iterates through the declarators in the port declaration to extract port names.
\item If multiple direction declarations are found for the same port, a warning is logged, and the first declared direction is retained.
\item Based on the port\textquotesingle{}s direction, the port name is added to the appropriate sets\+:
\begin{DoxyItemize}
\item {\ttfamily primary\+Inputs\+\_\+}\+: For input and inout ports.
\item {\ttfamily primary\+Outputs\+\_\+}\+: For output and inout ports.
\item {\ttfamily internal\+Wires\+\_\+}\+: For all ports (input, output, inout, and ports with unknown directions).
\end{DoxyItemize}
\item If a port has an unknown or missing direction, it\textquotesingle{}s treated as an internal wire, and a warning is logged.
\item The method avoids calling {\ttfamily visit\+Default} to prevent unexpected revisits of syntax nodes.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
The {\ttfamily logic\+Cache\+\_\+} update is commented out, indicating it\textquotesingle{}s part of a later processing step. 
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
Logs warnings for port declarations without headers, port declarators without names, and multiple direction declarations for the same port. 
\end{DoxyWarning}
