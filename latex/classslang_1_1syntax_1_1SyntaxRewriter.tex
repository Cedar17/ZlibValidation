Transforms the given syntax tree using the rewriter. The tree will be visited in order and each node will be given a chance to be rewritten (by providing \mbox{\hyperlink{classslang_1_1syntax_1_1SyntaxVisitor_aecb294b0686307633702e2bb937246b6}{visit()}} implementations in the derived class).

\begin{DoxyReturn}{Returns}
if no changes are requested, returns the original syntax tree. Otherwise, the changes are applied and the newly rewritten syntax tree is returned.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
lifetimes of new and old trees are independent from each other. If you shallow clone something from old tree into new one, you have to make sure that shared\+\_\+ptr to original doesn\textquotesingle{}t go out of scope too early. 
\end{DoxyNote}
