\doxysubsection{Detailed Description}
Manages SQLite database connections for writing Liberty LUT data. 

\mbox{\hyperlink{classLibDatabase}{Lib\+Database}} opens or creates a SQLite database file and provides methods to write timing look-\/up table (LUT) entries into the {\ttfamily lut\+\_\+entries} table.

Responsibilities\+:
\begin{DoxyItemize}
\item Create the {\ttfamily lut\+\_\+entries} table (DDL) on first use via \mbox{\hyperlink{classLibDatabase_a1ba443f5483f970be7231fe3d4a28169}{initialize()}}
\item Write one LUT record per call to \mbox{\hyperlink{classLibDatabase_a0bb1214018232120513f2caeac846cc9}{write\+Lut\+Entry()}}
\item Enforce idempotency via INSERT OR IGNORE
\end{DoxyItemize}

This class is deliberately scoped to Phase 2 of the aging.\+db migration\+: it only manages the lut\+\_\+entries table. Other tables (scenarios, k\+\_\+values, etc.) are managed by Python build scripts.
