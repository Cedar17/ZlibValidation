\item {\ttfamily when} 表达式可能很长（如 {\ttfamily (A2 $\ast$ B1 $\ast$ !\+B2 $\ast$ C1 $\ast$ !\+C2 $\ast$ D1 $\ast$ !\+D2)}）， 作为 TEXT 列会增大索引。\+SQLite 允许的最大索引条目长度为 $\sim$1\+KB，对典型 {\ttfamily when} 表达式足够
\item 对于无 {\ttfamily when} 条件的单元（多数简单门），{\ttfamily when=\char`\"{}\char`\"{}} 作为空字符串，仍保持唯一性
\item 此修复不会影响已有数据库的兼容性（当前无正式部署的数据库）
