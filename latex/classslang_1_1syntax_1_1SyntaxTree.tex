\doxysubsection{Detailed Description}
The \mbox{\hyperlink{classslang_1_1syntax_1_1SyntaxTree}{Syntax\+Tree}} is the easiest way to interface with the lexer / preprocessor / parser stack. Give it some source text and it produces a parse tree.

The \mbox{\hyperlink{classslang_1_1syntax_1_1SyntaxTree}{Syntax\+Tree}} object owns all of the memory for the parse tree, so it must live for as long as you need to access its syntax nodes.
