{\footnotesize\ttfamily bool Logic\+Comparator\+::extract\+Variables (\begin{DoxyParamCaption}\item[{const std\+::string \&}]{expr1\+\_\+raw,  }\item[{const std\+::string \&}]{expr2\+\_\+raw,  }\item[{std\+::vector$<$ std\+::string $>$ \&}]{sorted\+\_\+vars }\end{DoxyParamCaption})}



Extracts and validates variables from two expressions, ensuring they match. 

This function parses two raw expression strings ({\ttfamily expr1\+\_\+raw} and {\ttfamily expr2\+\_\+raw}) to identify potential variable names. It uses a regular expression to find identifiers and then validates them against a set of rules\+:
\begin{DoxyEnumerate}
\item The identifier must be a valid identifier as determined by the {\ttfamily is\+Identifier} function.
\item The identifier must not be a keyword or function name defined in the {\ttfamily keywords} set.
\end{DoxyEnumerate}

The function compares the sets of validated variables from both expressions. If the sets are identical, the variables are extracted, sorted alphabetically, and stored in the {\ttfamily sorted\+\_\+vars} vector. If the sets differ, an error is reported, and the differences between the sets are logged.


\begin{DoxyParams}{Parameters}
{\em expr1\+\_\+raw} & The raw string representation of the first expression. \\
\hline
{\em expr2\+\_\+raw} & The raw string representation of the second expression. \\
\hline
{\em sorted\+\_\+vars} & A vector to store the sorted list of unique variable names if the variable sets from both expressions match. This vector is cleared if the sets do not match.\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
{\ttfamily true} if the variable sets from both expressions match, indicating that the {\ttfamily sorted\+\_\+vars} vector contains the sorted list of unique variable names. {\ttfamily false} if the variable sets do not match, indicating an error.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
The {\ttfamily is\+Identifier} function is used to validate potential variable names. 

The {\ttfamily keywords} set contains a list of reserved words that cannot be used as variable names. 

The function uses spdlog for logging debug, trace, info, and warning messages. 
\end{DoxyNote}
